# SMS message samples (EN + TA)

Generated by `scripts/render_sample_messages.py` from `backend/safarset/notify/templates/{en,ta}.json`; a test keeps this file in sync.

* Tamil: **DRAFT TRANSLATION: NEEDS REVIEW BY A NATIVE TAMIL SPEAKER BEFORE ANY REAL USE**

Every journey message names the vehicle, where to board, the times, the destination and the group size, followed by the reason.
The reason is generated from the allocation's machine-readable reason, so both languages explain the same decision.
SMS cost: Tamil is sent as UCS-2 (70 characters per segment, 67 when joined); English is GSM-7 (160 / 153).
